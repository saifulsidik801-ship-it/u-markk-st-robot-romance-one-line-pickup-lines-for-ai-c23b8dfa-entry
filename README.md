One single-line pickup line, aimed at a robot/AI, written to `/output/entry.txt` by `main.py`.

> Are you a transformer? Because you have my full attention.

The punch is the machine premise itself: a transformer's attention mechanism. No batteries, no charging, no reboot — just the architecture, turned into a compliment.
